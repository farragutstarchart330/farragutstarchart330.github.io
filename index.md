## 🚀 How to Create Your First Program

Once the installation finishes, open the application from your desktop or Start menu. Follow these steps to generate your first calculator script:

1. **Describe your goal:** In the main text box, type what you want the calculator to do. For example, you might write: "Calculate the area of a circle given the radius" or "Find the roots of a quadratic equation."
2. **Review the draft:** The tool generates the MicroPython code for you. Read through the preview to see how it works.
3. **Run the check:** Press the "Verify" button. The software tests the code against TI-84 memory limits and syntax rules to prevent crashes.
4. **Save the file:** If the check passes, press "Download Program." Save the resulting file to a folder on your computer.

## 🔌 Transferring Files to Your Calculator

After you save the program to your computer, you must move it to your calculator:

1. Connect your TI-84 Evo to your computer using a USB cable.
2. Open the TI-Connect CE software. (Download this from the official Texas Instruments portal if you do not have it).
3. Drag the file you saved from your computer into the TI-Connect window.
4. Select "Send to Calculator."
5. Disconnect the cable. Your program now appears in the "Program" menu on your calculator.

## 🛠 Troubleshooting common issues

If you encounter a problem, consider these solutions:

*   **Installer blocked:** Windows might show a warning. Click "More info" and then "Run anyway" if the publisher is verified as the repository owner.
*   **Connection errors:** Ensure your USB cable transmits data. Some cables only charge devices. Try a different port if the calculator does not appear in TI-Connect CE.
*   **Syntax errors on device:** If the calculator shows a syntax error, ensure you chose the correct TI-84 Evo model in the settings menu of the scripter tool.
